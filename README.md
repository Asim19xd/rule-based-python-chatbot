# Rule-Based AI Python Chatbot

A simple rule-based chatbot built using Python.

## Features
- Time-based greeting using datetime
- Rule-based responses using dictionary
- Continuous chat using while loop
- Exit command using "bye"

## Technologies Used
- Python
- datetime module

## How to Run
1. Clone the repository
2. Run `python chatbot.py`
3. Start chatting

## Example
User: hello  
Bot: Hi, Welcome! How may I help you?
